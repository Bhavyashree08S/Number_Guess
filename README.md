

# 🎯 Number Guessing Game 

## 📌 Description

This is a simple command-line based Number Guessing Game built using Python.
The program randomly selects a number between 1 and 100, and the user has to guess the correct number. The game provides helpful hints after each guess, making it interactive and fun to play.

---

## 🚀 How It Works

* The program randomly selects a number between 1 and 100.
* The user is asked if they are ready to play the game.
* The user enters a guess.
* The game gives hints if the guess is:

  * Too high
  * Too low
  * Close to the correct number
* The game continues until the user guesses the correct number.
* Once guessed correctly, the program displays a success message and exits.

---

## 🛠️ Technologies Used

* Python
* `random` module
* Loops and Conditional Statements

---

## ▶️ How to Run

1. Make sure Python is installed on your system.
2. Clone this repository or download the file.
3. Run the program using:

```bash
python guess_num.py
```
